# RecipeScaler
Ask the user how many ingredients are in a recipe, then for each one ask for its name, amount, and unit. Ask for a scaling factor, then print each ingredient with its scaled amount (unit unchanged).
<br>
Topics Covered:
<br>
1. Functions (def)
2. User input (input())
3. Type conversion (int(), float())
4. Lists ([])
5. Tuples (())
6. for loops
7. range()
8. append() method
9. Tuple unpacking
10. Arithmetic operations (*)
11. Formatted strings (f-strings)
12. Printing output (print())
